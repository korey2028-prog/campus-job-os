# 27 届校招岗位数据集

`27届校招岗位.csv`：国内 2027 届校招 / 实习岗位汇总，每天更新。UTF-8（带 BOM，Excel 可直接打开），一行一条招聘。

| 列 | 说明 |
|--|--|
| 岗位ID | 原表编号 |
| 公司、岗位 | 岗位可能是多个，用顿号分隔 |
| 届次、招聘类型 | 如“26/27届”“27届秋招”“实习” |
| 学历、工作地 | 学历门槛；工作地为原文，可能含多个城市 |
| 截止时间、截止日期 | 截止时间是原文（可能是“尽快投递”）；截止日期是能确定的日期 |
| 企业性质、所属行业 | |
| 知名企业、免笔试、部分岗位免笔试、不限专业 | 是 / 空 |
| 公告链接、投递链接、投递渠道备注 | 以企业官方公告和投递入口为准 |
| 更新日期 | 这条记录最近一次更新 |

数据来自公开招聘信息的整理表，经整理方同意公开。投递前请以企业官网公告为准。
